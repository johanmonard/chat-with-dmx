# World maps

One file per world (`projects.md`, `marketing.md`, `documentation.md`): what the world holds, where, which filter reaches it, and what it does NOT hold (with where to look instead). The `world_map` tool returns the file followed by live counts from the index.

Outline: `# <World> - map`, then `## What this world is for`, `## Kinds of information` (table), `## Not in this world - look there`, `## Pitfalls`. Keep each file under about 5,000 characters (the live overview needs the rest of the 15,000).

These are the first drafts. The live copies are in `U:\DMX-RAG\maps\` and are edited there; `dmx.ps1 pull` copies them to each machine, and `dmx.ps1 map -World <name>` shows what Claude will see.
