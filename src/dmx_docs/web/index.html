Choose the folders to index, scan them, and connect Claude Desktop.

Folder settings changed since the last scan. Excluded or removed folders are already hidden from Claude; run a scan to index new folders and clean up the index.

Folders to index

    Expand a folder and untick the subfolders you don't want indexed. Everything inside an unticked folder is skipped.

    Scan

    Only new, modified and deleted files are processed. You can stop a scan at any time; the next one continues from there.
